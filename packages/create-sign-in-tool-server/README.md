# `@emseepea/create-sign-in-tool-server`

Create a private, standalone Em See Pea project with a tool that requires
sign-in. The package builds its starter from the maintained
[sign-in tool example](https://github.com/emseepea/emseepea/tree/main/examples/protected-no-ui).

## Create the Project

This initializer is queued for the next pre-alpha release and is not yet
available from npm.

```sh
npm init @emseepea/sign-in-tool-server@next -- my-server
```

```sh
cd my-server
npm install
npm test
npm run lint
npm start
```
