# `@emseepea/create-tool-server`

Create a private, standalone Em See Pea project with one public, read-only
tool. The package builds its starter from the maintained
[first public tool example](https://github.com/emseepea/emseepea/tree/main/examples/basic-no-ui).

## Create the Project

This initializer is queued for the next pre-alpha release and is not yet
available from npm.

```sh
npm init @emseepea/tool-server@next -- my-server
```

```sh
cd my-server
npm install
npm test
npm run lint
npm start
```
