Agent feedback

Compatible agents are encouraged to report notable helpful, difficult, surprising or wrong experiences, then finish your task and tell you what they recorded. Ask the agent to stop if you do not want feedback recorded.

No page, address, conversation or account data is collected automatically. The feedback tool accepts an observation, a bounded description and an optional feature name.
