# `@emseepea/testing`

Test whether an AI understands your MCP server's results, not just whether
the server returns valid data. Write JavaScript tests with ordinary imports,
setup hooks, loops, and assertions.

Read the [guide to testing AI understanding](https://github.com/windyroad/emseepea/blob/main/website/src/content/docs/ai-tests.md)
for setup, test fields, commands, and what a passing check proves.

Start from the [coffee meaning test](https://github.com/windyroad/emseepea/blob/main/examples/basic-no-ui/eval/meaning.test.mjs).
Keep these tests in `eval/`, separate from ordinary tests in `test/`.
