# `@emseepea/create-multi-instance-sqlite-server`

Create a private, standalone Em See Pea project that runs two local server
instances against one SQLite file. The package builds its starter from the
maintained
[multi-instance SQLite example](https://github.com/emseepea/emseepea/tree/main/examples/multi-instance).

## Create the Project

This initializer is queued for the next pre-alpha release and is not yet
available from npm.

```sh
npm init @emseepea/multi-instance-sqlite-server@next -- my-server
```

```sh
cd my-server
npm install
npm test
npm run lint
npm start
```
