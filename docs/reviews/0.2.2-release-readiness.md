## What Changes for Users

The eight maintained examples now have clear, task-based directory names that
match their colocated initializer packages. Each README explains when to choose
that template and gives its untagged `npm init` command.

The examples use a garden-pea theme. The API-backed example calls iNaturalist
and passes selected schema-valid values through without a closed translation
table. This lets future valid provider values reach an AI caller without an Em
See Pea release.

Public packages now publish to npm's default `latest` channel. Current commands
therefore omit `@next`.
