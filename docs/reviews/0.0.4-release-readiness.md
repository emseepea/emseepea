## What Changes for Users

Each maintained example has one public initializer package. The documented
commands use `npm init @emseepea/<starter>@next -- my-server`. Generated
projects are private and standalone. They reject path traversal, non-empty
destinations, and overwrites. They retain lint, ordinary tests, and semantic
tests. The two UI starters also retain browser accessibility tests.

The separately installable React renderer and Tailwind stylesheet join the
public package set. They remain optional and do not add frontend dependencies
to the server package.
