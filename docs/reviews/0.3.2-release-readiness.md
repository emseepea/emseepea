## What Changes for Users

Every maintained initializer now describes each public input and output
property in its MCP schema. These descriptions explain meanings, units, effect
boundaries, provider concepts, and other distinctions a model needs when using
the tool. The resources-and-prompts initializer similarly describes its prompt
argument.

The framework README now demonstrates Zod `.describe()` metadata and explains
that Em See Pea includes it in the MCP schema sent to clients.
