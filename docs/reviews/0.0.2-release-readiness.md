# Release Readiness for Em See Pea 0.0.2

Date: 2026-08-30

This release replaces 0.0.1, which did not include the files needed to run the
public packages. Version 0.0.1 is deprecated on npm.

## What This Release Corrects

- The release job builds both public packages before inspecting or publishing them.
- Each package builds itself when a maintainer runs an ordinary `npm pack`.
- Package inspection checks that every public import and command is present.
- Registry checks detect publication even if the Changesets action does not report it.
- Git tags and GitHub releases are created only after both downloaded packages work.

## What Must Pass

The exact commit being published must pass:

- tests and dependency checks on Node.js 22 and 24
- the performance check for JSON input and output
- repeated checks that an AI understands each example correctly
- checks that both public packages contain the files users need
- npm trusted publishing
- npm checks for package signatures and source evidence
- checksum checks on the downloaded packages
- a clean install from npm
- import, audit, and basic public MCP call checks
- direct checks against npm and GitHub

Any missing package, moved `latest` tag, wrong source commit, or partial
publication stops the release before Git tags and GitHub releases are created.

## Known Limitation

npm created a `latest` tag for the first 0.0.0 package even though publication
used the `bootstrap` tag. npm refuses to remove it. Do not install `latest`.
Install pre-alpha versions from the `next` tag.
