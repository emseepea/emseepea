## What Changes for Users

Maintained examples and framework guidance now name schemas after the properties
that receive them, such as `inputSchema` and `outputSchema`. Tool definitions
can therefore use object shorthand without making readers translate between two
names for the same schema.

The API-backed example declares compatible provider fields once. Its public
response schema extends that checked provider response with the source fields
owned by the tool, and the response passes the checked provider values through.
The multi-instance example keeps its explicit mapper because it performs real
field renaming and aggregation.
