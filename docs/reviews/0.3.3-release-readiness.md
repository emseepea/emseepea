## What Changes for Users

Tool handlers can now return only validated structured `data`. Em See Pea sends
that data as `structuredContent` and also serializes it as JSON text for clients
that do not consume structured content. A handler can still provide custom text
when it adds useful meaning.

All maintained tool examples use the smaller `{ data }` result shape. Their
initializers carry the same pattern into generated projects.
