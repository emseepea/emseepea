## What Changes for Users

The server adds optional deterministic HTTP route discovery through
`registerRoutes`. A project can keep explicit Fastify route registration or
load flat, method-first route modules from one local directory during startup.

The HTML UI initializer now uses route files for documents, form submissions,
and stylesheets. The React UI initializer also uses a route file for its browser
script. Their server entry points remain small while their generated projects
keep the same accessible UI behavior.
