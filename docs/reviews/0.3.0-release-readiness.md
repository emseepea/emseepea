## What Changes for Users

Semantic tests now read as ordinary JavaScript conversations. A test creates a
conversation, sends one or more prompts, and uses focused assertions for exact
tool calls, no calls, literal response content, and model-judged meaning.

The API supports follow-up prompts using the actual history from the same
trial. Context remains optional so tests do not add hidden guidance by default.
All eight maintained examples use this API, and generated projects retain those
tests from their example source.

Selected calls execute through the official Model Context Protocol client
before assertions run. The documentation requires isolated, effect-safe test
servers and fixtures and forbids production targets.
