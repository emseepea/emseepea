## What Changes for Users

Each maintained example is now also its public `npm init` package. This gives
each example and initializer one repository location and one README. The
example directory remains the maintained template source.

The generated projects remain private and standalone. The initializer packages
have no runtime dependencies of their own, so npm can start them before the
generated project installs its dependencies.

The API-backed example now passes schema-valid provider values through by
default. It does not maintain a closed translation table for values that an AI
caller can already understand from the declared schema.

The server patch records that pass-through principle. The React patch updates
its server dependency for this batch.
