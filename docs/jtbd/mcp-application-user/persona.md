# Model Context Protocol Application User

## Who

A person completing a task with an artificial intelligence (AI) application
that uses an Em See Pea server.

## Context Constraints

- Their task matters more than managing feedback or support tickets.
- They may not know which MCP tool the AI used.
- They should know when the AI records feedback about their experience.

## Pain Points

- Surveys and permission prompts interrupt the task.
- One-way feedback provides no useful return path.
- Repeating an already reported problem adds friction.
