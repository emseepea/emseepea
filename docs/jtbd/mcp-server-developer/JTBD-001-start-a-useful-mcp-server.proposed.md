# JTBD-001: Start a Useful Model Context Protocol Server

## Job Statement

When I start a Model Context Protocol (MCP) project, I want a small working
server with clear defaults, so I can focus on the tools I am creating.

## Desired Outcomes

- Copy or generate a working example with little boilerplate.
- Run it locally with one documented command.
- Understand which code belongs to the framework and which code belongs to me.

## Persona Constraints

The starting point must be easy to copy into a new project and modify.

## What Developers Do Today

Developers assemble a Model Context Protocol software development kit (SDK),
web server, validation, and examples themselves.
