# Model Context Protocol Server Developer

## Who

A TypeScript developer building a Model Context Protocol (MCP) server for an
artificial intelligence (AI) application.

## Context Constraints

- They want to start with little boilerplate.
- They may need authentication, streaming, or a user interface later.
- Correct data is not enough if an AI misunderstands what the data means.

## Pain Points

- Model Context Protocol transport and validation details distract from the tool being built.
- Optional features can make a small server hard to understand.
- Ordinary tests do not catch misleading tool descriptions or results.
